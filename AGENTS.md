As of verified source2.1.8/code11, the Driver app provides two user-initiated activation paths:
1. **Manual phone entry**: The registered Iranian mobile number is normalized and passed through the shared activation owner. First activation requires carrier-origin Hub proof and the encrypted device-bound grant. A retained scoped credential can rediscover only its own registered phone; typing a number alone does not authenticate it (`EnrollmentManager.kt`, `BootstrapCoordinator.kt`, `EnrollmentContract.kt`). Activation latency is unmeasured.
2. **Automatic SIM bootstrap**: The explicit fallback action creates a durable pending activation. Opening or resuming a clean installation does not create an anonymous challenge. Recovery checks the saved phone/device and durable stopped decision (`DriverActivationRuntime.kt`).
3. **WorkManager policy**: Background recovery uses `KEEP` for genuine pending work; explicit user retry uses `REPLACE`. Cancellation revokes the active generation and the unique work before late callbacks can stage a grant or change readiness. Reset preserves the valid private identity/profile while stopping forwarding and revoking consent (`DriverBootstrapWorker.kt`, `EnrollmentManager.kt`).

One selected subscription owns each modem attempt and its callbacks. A later bounded retry rotates subscriptions. Hub proof work is keyed by normalized actual carrier origin plus nonce and checks the current enabled/consent/token/endpoint/device values after cellular acquisition (`BootstrapSmsDispatch.kt`, `HubBootstrapWorker.kt`). `CellularEgress` selects a NOT_VPN network; it does not prove the egress country or override Android VPN lockdown.

The Hub app (`APP_ROLE == "HUB"`) acts as the fleet gateway receiving and relaying verified driver OTP envelopes (`BP1#...`). A public Hub upgrade retains its stored private profile. A factory-clean Hub uses an organization-private, external one-use install capability, followed by a device-scoped credential. The private installer/profile is kept outside the public release and source tree; public tuning/update documents carry no credential. Source references are `HubInstallManager.kt`, `HubInstallRuntime.kt`, `HubInstallContract.kt`, `DriverActivationRuntime.kt`, `BootstrapSmsDispatch.kt` and `app/build.gradle.kts`.
