# Forward BarPro agent reference

This guide applies to the Android Forwarder repository. Consult [RELEASE_2_1_4.md](RELEASE_2_1_4.md) for the dated 2026-11-03 publication, installation behavior, artifact hashes and evidence limits, and [AUTOMATIC_ACTIVATION.md](AUTOMATIC_ACTIVATION.md) for protocol/source verification. Older README and activation sections are historical snapshots; confirm current code before using their HTTP, typed-phone, token or test-count statements.

The 2.1.4/code7 Driver uses carrier-origin, device-bound automatic bootstrap after permissions and initial internet; an unset SMS SIM still needs Android system selection. A public Hub upgrade retains its stored private profile. A factory-clean Hub uses an organization-private, external one-use install capability, followed by a device-scoped credential. The private installer/profile is kept outside the public release and source tree; public tuning/update documents carry no credential. Source references are `HubInstallManager.kt`, `HubInstallRuntime.kt`, `HubInstallContract.kt`, `DriverActivationRuntime.kt`, `BootstrapSmsDispatch.kt` and `app/build.gradle.kts`.

Use the exact reviewed version properties for release builds and verify native APK versionCode/versionName, signer, debuggable flag and assets before delivery. The dated private build required both `--no-build-cache` and `--no-configuration-cache`. Keep the retained Android signer and ECDSA channel key backed up privately. Preserve valid private identities and explicit stop/consent decisions during recovery (`AutomaticEnrollmentRecoveryTest`, `MaintenanceConfigRaceTest`, `HubInstallActivationTest`).

The dated release receipt distinguishes source tests/public downloads/private packaging from real installation, carrier proof, health and OTP delivery. It records no real capability redemption. Never infer current handset or backend health from this release record. Backend/UTCMS claims belong to BarPro's own runtime contracts and timestamped evidence, not this Android artifact receipt.

As of the 2026-11-03 repository preservation receipt, local/origin branches contain only `main`. Earlier tracked edits, branch refs and superseded untracked tests remain recoverable in the verified private backup and stash identified in the release receipt. Do not reapply their older typed-phone/link requirements or remove the shared Hub test guards without reviewing the recorded supersession reasons and the current owner's request.
